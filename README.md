<p align="center">
  Sweep finds the gigabytes that macOS files under System Data, names them, and removes the ones you select.
</p>

<p align="center">
  <a href="https://github.com/FlorianBx/sweep-releases/releases/latest/download/Sweep.dmg"><strong>Download Sweep for Mac</strong></a>
  <br>
  For Macs with Apple silicon.
</p>

## Install

1. Download `Sweep.dmg`.
2. Open it and drag Sweep into Applications.
3. Open Sweep.

Sweep checks for new versions when it starts and offers to update itself.

## About this repository

This repository only holds the releases of Sweep. Each release has the disk image, the update archive and the `latest.json` file that the app reads to find updates.
